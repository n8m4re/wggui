# Flatpak

App ID `io.github.n8m4re.WGGUI`, manifest `packaging/flatpak/io.github.n8m4re.WGGUI.yml`.

| Component | Source |
|---|---|
| Runtime/SDK | `org.kde.Platform`/`org.kde.Sdk` 6.11 (includes Python 3.13, OpenSSH, `ssh-keygen`, `awk`) |
| PySide6 | Base App `io.qt.PySide.BaseApp` 6.11 (official, github.com/flathub/io.qt.PySide.BaseApp); `cleanup-BaseApp.sh` per their README |
| Python packages | `packaging/flatpak/python3-deps.json` – wheels with sha256 from `uv.lock`, generated by `scripts/flatpak_deps.py` (buildable offline) |
| App | `src/wggui` directly into `/app/lib/python3.13/site-packages` (no build backend needed), launcher `packaging/flatpak/wggui.sh` |
| Desktop/AppStream/Icon | `io.github.n8m4re.WGGUI.desktop`, `.metainfo.xml`, `.svg` (+ `-symbolic.svg`) |

## Build

```bash
# once, for your user only
flatpak install --user flathub org.flatpak.Builder org.kde.Sdk//6.11 org.kde.Platform//6.11 io.qt.PySide.BaseApp//6.11
scripts/flatpak-build.sh            # build + install for your user
scripts/flatpak-build.sh --bundle   # also build-flatpak/wggui.flatpak (single file to share)
flatpak run io.github.n8m4re.WGGUI
```

After changes to `uv.lock`: run `python3 scripts/flatpak_deps.py` (the build script checks this itself).

## Sandbox permissions

| Permission | Purpose |
|---|---|
| `--share=network` | SSH to the servers |
| `--socket=ssh-auth` | SSH agent (default “System”) |
| `--filesystem=~/.ssh:ro` | ssh config, `known_hosts`, own key files – read only |
| `wayland`, `fallback-x11`, `ipc`, `dri` | UI |

Inside Flatpak, `ssh` cannot write new host keys to `known_hosts` (read only): confirm a new server once in the terminal with `ssh <target>` beforehand – as you would without Flatpak.

## Data

Everything under `~/.var/app/io.github.n8m4re.WGGUI/` (DB, log, generated SSH keys, language setting) – separate from the source installation. To migrate: copy `~/.local/share/wireguard-gui/wggui.db` to `~/.var/app/io.github.n8m4re.WGGUI/data/wireguard-gui/`.
