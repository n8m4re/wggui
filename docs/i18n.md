# Internationalization

Languages: German (source strings in the code), English, Spanish, Italian, Simplified Chinese, Japanese.

| What | How |
|---|---|
| Choose language | **&View → Language** (takes effect on next start), otherwise `WGGUI_LANG=en`, otherwise the system language. Unsupported system language → English. |
| Stored in | `QSettings` → `~/.config/wireguard-gui/wireguard-gui.conf` (Flatpak: `~/.var/app/<id>/config/…`) |
| Catalogs | `src/wggui/locale/<language>.po` (GNU gettext PO). The app reads them directly (`wggui/i18n.py`); no `msgfmt` needed. |
| Qt's own buttons | `qtbase_<language>.qm` from the Qt installation (`install_qt_translation`) |
| Not translated | Log (developer tool), server commands and output |

## In the code

```python
from wggui.i18n import N_, _, ngettext

label.setText(_("Host hinzufügen…"))                                   # fixed text
msg = _("Adresse {ip} ist schon vergeben.").format(ip=ip)              # Platzhalter benannt, kein f-String in _()
text = ngettext("{n} Änderung", "{n} Änderungen", n).format(n=n)       # plural
CHOICE = N_("Nichts tun")   # Konstante beim Import: nur markieren, bei der Anzeige _(CHOICE)
```

- Do not wrap f-strings in `_()`: the text must be constant or extraction cannot find it (`scripts/i18n.py` aborts).
- Use `N_()` for module-level constants (column names, choice identifiers); logic compares the German identifier, while `_(kennung)` displays the translation.
- Never compare displayed text (e.g. status “active”) – it is translated.

## Maintaining catalogs

```bash
python3 scripts/i18n.py extract            # new/changed strings into all catalogs (translations are kept)
python3 scripts/i18n.py missing es > x.json # missing translations of one language as JSON
python3 scripts/i18n.py fill es x.json      # fill in translations
python3 scripts/i18n.py check               # complete? placeholders equal? (test: tests/unit/test_i18n.py)
```

Translation rules: Keep placeholders `{…}`, HTML tags, technical terms (WireGuard, PublicKey, AllowedIPs, wg syncconf …), and paths unchanged; use exactly one `&` for a keyboard shortcut (Chinese/Japanese: `(&S)` at the end); plurals: two forms (de, en, es, it), one form (zh, ja).

Initial translation on 2026-11-15: English by hand; Spanish/Italian/Chinese/Japanese with Codex (using German + English as references), checked with `check` and spot checks. A review by native speakers is still welcome.
